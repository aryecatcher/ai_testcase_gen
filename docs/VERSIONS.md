# 版本说明

## 当前版本线

### Web V2

- 前端：`frontend/`
- 后端：`src/`
- 形态：`Vue 3 + FastAPI`
- 场景：推荐新用户、团队协作、服务器部署

特点：

- 界面更完整
- 支持启动检查
- 支持后台生成任务与状态持久化
- 更适合 PostgreSQL 和 Linux 服务器部署

### Legacy V1

- 前端：`ui/`
- 后端：`src/`
- 形态：`Streamlit + FastAPI`
- 场景：兼容旧流程、单机快速试用

特点：

- 启动简单
- 单文件 UI 便于快速改动
- 不适合作为长期主线产品形态

## 推荐使用关系

- 新部署：优先 `Web V2`
- 历史兼容：使用 `Legacy V1`
- 对外发布：建议只持续发布 `Web V2`

## 推荐标签策略

- `v2.x.x`
  - Web V2 稳定版本
- `v1.x.x`
  - Legacy V1 兼容版本

## 推荐分支策略

- `main`
  - 稳定可发布主线
- `develop`
  - 日常集成分支
- `release/v2.x.x`
  - 发布预备分支
- `hotfix/...`
  - 紧急修复分支
