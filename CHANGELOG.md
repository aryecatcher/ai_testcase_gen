# Changelog

All notable changes to this project are documented in this file.

The format follows Keep a Changelog and the project is intended to use Semantic Versioning.

## [Unreleased]

### Added

- Added `Web V2` frontend based on `Vue 3 + TypeScript + Vite`
- Added persistent generation jobs and background worker queue
- Added PostgreSQL deployment support and initialization script
- Added cross-platform bootstrap and startup scripts
- Added Docker deployment files for frontend, backend, and PostgreSQL
- Added repository-level documentation for versions and deployment matrix
- Added startup status checks for frontend and backend health visibility

### Changed

- Simplified dashboard and project stats execution metrics display
- Improved review/export page quality characteristic fallback behavior
- Improved generation progress rendering and latest batch filtering
- Standardized project setup documentation for Windows and Linux

## [v2.0.0] - 2026-04-21

### Added

- Established `Web V2` as the recommended deployment path
- Added Linux-oriented deployment documentation and server guidance
- Added release-oriented repository packaging
